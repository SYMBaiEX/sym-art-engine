# Security policy

Please do not file public issues for vulnerabilities that could expose local
files, execute unintended commands, corrupt collection output, or bypass
validation. Use GitHub's private security-advisory reporting for
[`SYMBaiEX/sym-art-engine`](https://github.com/SYMBaiEX/sym-art-engine/security/advisories/new).

Include the affected version, reproduction steps, impact, and any safe proof
of concept. Do not include private collection assets, seed material, wallet
keys, API tokens, or production metadata.

Supported releases are the latest published npm version and the current `main`
branch. We will acknowledge a report, assess it, and coordinate a fix before
public disclosure where practical.
